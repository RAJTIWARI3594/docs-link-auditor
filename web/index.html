in your docs folder.

Select a local folder containing Markdown files. The browser checks relative file links and heading anchors without uploading the files.

This works in browsers that support folder selection. Markdown files are read locally in this tab.

Browser edition checks inline Markdown links, local file targets and ATX heading anchors in selected Markdown files. External URLs are not fetched. It checks up to 500 Markdown files / 50 MB and cannot inspect files you did not choose; this is a practical checker, not a full CommonMark parser. Files are not uploaded.
